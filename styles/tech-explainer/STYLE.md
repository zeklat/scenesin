# Technology / Software Explainer Style Guide (scenesin)
Author: Anouar Zeklat (Instagram: @anouar.co)

Developer-first, sleek tech explainer style featuring dark-mode code editors, animated terminal sessions, browser mockups, and microservice architecture node diagrams.

## 1. Visual Aesthetics
- **Dark Developer Theme**: GitHub / VS Code dark mode background `#0E1117`, header `#21262D`, window background `#161B22`.
- **Syntax Highlighting**: Keywords `#FF7B72`, functions `#D2A8FF`, strings `#A5D6FF`, numbers `#79C0FF`.
- **Motion**: Line-by-line syntax-highlighted typing cursor, blinking terminal carats, and glowing packets traversing API node graphs.

## 2. Formats Supported
- `9:16` (1080x1920) for developer shorts & TikTok tech tips.
- `16:9` (1920x1080) for software architecture deep dives and YouTube tutorials.

## 3. Key Components
- `K.codeEditor({ x, y, w, h, title, code, activeLine, t })`: Realistic editor with macOS traffic lights and syntax tokens.
- `K.terminal({ x, y, w, h, title, lines, t })`: Command prompt with commands, outputs, and checkmarks.
- `K.apiArchitectureDiagram({ x, y, w, h, t })`: Dynamic node graph with pulsating data packets.
